# CHIBI NAIL SALON LP

静的HTML/CSS/JavaScriptのみで制作したGitHub Pages向けLPです。

## 更新箇所

- 予約URL・住所・料金など: `index.html` 内の `[ ]` 表記を編集
- ギャラリー: `assets/images/` に写真を置き、`js/main.js` の `galleryItems` に追加
- ロゴ: `assets/logo/chibi-nail-logo.svg`

## 公開

GitHubリポジトリの Settings > Pages で、公開対象ブランチと `/ (root)` を選択してください。
